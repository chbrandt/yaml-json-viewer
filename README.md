# YAML-JSON-Viewer Chrome extension

Pretty-print YAML/JSON content instead of downloading them.

## Install

1. Open Google Chrome and type chrome://extensions/ into the URL bar.
2. Turn on *Developer mode* (the toggle switch in the top right corner).
3. Click the *Load unpacked* button in the top left.
4. Select the folder/path to this repo.

Test it by opening any YAML/JSON file on the web with your (Chrome) browser.
Examples:
- [https://github.com/yaml/yaml-test-suite/tree/main/src](https://github.com/yaml/yaml-test-suite/tree/main/src)
